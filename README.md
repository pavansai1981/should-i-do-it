# Should I Do It? — MVP

A mobile-first decision-support website MVP.

## Run
Open `index.html` in a browser.

## Current features
- Landing page
- 5-step decision questionnaire
- Client-side validation
- Personalized preview score
- ₹49 checkout placeholder
- Responsive mobile design
